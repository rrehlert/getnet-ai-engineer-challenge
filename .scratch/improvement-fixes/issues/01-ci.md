# 01: CI: tests and container smoke test

**What to build:** every push and pull request runs the test suite and proves the container builds and starts. A GitHub Actions workflow installs with `uv sync --locked` and runs pytest, then builds and starts the stack with compose, waits for `/health` to return 200, POSTs an empty body to `/chat` and expects 422, and tears the stack down. No secrets: the app must start and build the index without an LLM key.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Workflow runs on push and pull request
- [ ] Test job installs from the lockfile and runs pytest
- [ ] Smoke job builds and starts the stack with compose and waits for `/health` = 200 with a bounded timeout
- [ ] Smoke job checks `/chat` with an empty body returns 422
- [ ] Stack is torn down even when a step fails
- [ ] No secrets or LLM key used
- [ ] Workflow passes on the branch
